# The dart blaster's sounds

These are the owner's picks, made by ear on 2026-11-20 from the audition page the sound session published
(59 candidates across eight cues). None is added, swapped or removed without the owner having heard it.

| File | What it is | The pick | How it was made | Licence |
|---|---|---|---|---|
| `equip.ogg` | Taking the blaster in hand | `equip-synth-b` | Made in code | Clear: original |
| `unequip.ogg` | Putting it away | `unequip-synth-b` | Made in code | Clear: original |
| `reload.ogg` | Five darts in, the slide pulled and let go (1.37 s) | `reload-asm-a` | MOSS-SoundEffect v2.0 renders of one dart click and a slide, placed in order in code | Clear: Apache-2.0 model |
| `fire.ogg` | One dart leaving | `fire-synth-c` | Made in code | Clear: original |
| `impact.ogg` | A dart sticking to something | `impact-1` | MOSS-SoundEffect v2.0 | Clear: Apache-2.0 model |
| `impact-2.ogg` | The same, a second take: one of the two is heard each time | `impact-synth-c` | Made in code | Clear: original |
| `fall.ogg` | A dart letting go and dropping | `fall-synth-b` | Made in code | Clear: original |
| `hit.ogg` | A dart reaching a person, heard by them and those near | `hitBody-3` | MOSS-SoundEffect v2.0 | Clear: Apache-2.0 model |
| `tick.ogg` | The tick whoever fired hears, with the hit mark | `hitMarker-synth-b` | Made in code | Clear: original |

All are mono Ogg Opus at 48 kHz, levelled like the kit's own cues. The licences are as the sound session
reported them, and are not legal advice. `scripts/make-items.mjs` copies each beside the models under its
hash, which is the name the blaster's description knows it by.
