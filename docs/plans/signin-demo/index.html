What is happening

    
    
      
  1. This page embeds a hidden signer from your sign-in address. It can ask the signer things. It can't read it.
    2. 
      
  2. The window is your sign-in address's own page. It finds its own signer inside this page, shows you this page's address as your browser reports it, and waits for Allow.
    3. 
      
  3. On Allow, BitLogin moves a key that can only sign from the window to the signer, without it passing through either page.
    4. 
      
  4. The signer then signs notes and reactions for this site, marks each with this site's address, and refuses everything else. It remembers this site on this device, so reloading the page asks nothing. Signing out here forgets it.
