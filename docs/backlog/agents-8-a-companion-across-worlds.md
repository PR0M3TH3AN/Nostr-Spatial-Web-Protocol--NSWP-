## What it is

The same character, with the memories the visitor approved, in two worlds on
different sites, with each world deciding afresh what it may do there. The
pack takes it that a door ends everything running, so the companion is saved
and restored. In BitPortal the shell now stays as one page with each world in
a frame (`menus-are-the-clients`), so a companion could run in the shell and
stay, as the visitor's music will; that needs words between the shell and a
world for what the agent sees and may do. Also here: the same contract for
Godot.

## Done looks like

A companion goes with its visitor to another world's site as itself, as a new
instance under that world's rules, with nothing secret carried in a link.
