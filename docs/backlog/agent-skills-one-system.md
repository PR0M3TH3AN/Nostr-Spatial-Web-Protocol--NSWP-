# Agent skills: one system, good docs and tooling, shared on Tessera

- **Asked:** 2026-11-25, by the owner, in the agents' playground: "The
  room and arena skills should become one system. Yes please."; "Yes we
  need very good docs and agent tooling."; "We could use Tessera to share
  and discover skills."
- **Who:** the agents' playground (`nswp-agents`); then the kit, by names
  given.
- **State:** the one system first (the playground's next), then docs and
  tooling, then Tessera.

## Wanted

1. **One skill system:** the room's skills and the arena's become one
   offer-and-score system with one picker (rules first, variety only
   among close choices, a model asked only when the rules are unsure),
   every battery re-measured against today's numbers.
2. **Docs and tooling a coding agent can follow:** a developer guide, a
   skill template, a checker, and a skills-on-and-off harness; then a
   small new game built with it, measured against building from scratch.
3. **Skills shared on Tessera:** a skill as a plugin (its offers, checks,
   tests and a scenario). Publishing to Tessera is the owner's alone:
   sessions make drafts or private listings only.

## Must not

- Publish anything to Tessera or relays without the owner's own word.
