# Small trials of kinds of game an agent might suit

- **Asked:** 2026-11-24. The owner, thinking about where a tree of choices
  might matter: "Could you give me a hypothetical game concept that might be
  best for tree based JEV branches? Like a sims game. Or Civ game?
  Management or clue discovery and mystery solving. Like the actual game
  Clue?" And then: "Could we do some simple versions test for these kind of
  games after the shooting range?"
- **Who:** the `nswp-agents` session, in its playground only. Briefed
  2026-11-24, after the shooting range.
- **State:** queued after the range. Trials, not games: nothing for the kit,
  BitPortal or any live world. Part of `ai-keys-and-agents`, which is last
  and not a priority.

## Why these three

Each is a different reading of "a tree", and each is a case the tree test
did not try (`docs/plans/agents-lessons.md`, "Not yet known").

1. **A house of people with needs** (a life game). A choice is need, then
   thing, then action. Things say what they offer, which is the declared
   room's own shape. Decisions come every few seconds, when something
   changes, so it is the tree as where an agent is: it stays at what it is
   doing until a need or an event moves it.
2. **A mystery in that house.** Built on the first: one of the people does
   something, chosen through the same choices given a reason to. What
   happened is then real and written down. Where each was is a record;
   what each saw is what was in their sight at the time (the text view,
   used as a witness's knowledge); what each says is the chat model
   speaking from their true memory, with one told to hide. Looking into it
   is an order that names nothing, where there are no words to cut the
   choices down by.
3. **A small settlement, played in turns** (a management game). Things need
   other things first. Since effects are data, plain code can look several
   steps ahead, where the engine today looks one; JEV moves each piece.
   Turns make its speed not matter.

Not a copy of any game that exists: the kinds, not anyone's rooms, people,
cards or rules.

## What each should measure

- **The house:** decisions and tokens an hour for each person; whether the
  days look sensible (nobody starves, nobody does one thing for ever, people
  differ); staying at a leaf against asking the whole question each time.
- **The mystery:** whether what witnesses say agrees with the record;
  whether the one hiding keeps their story over a whole game; whether the
  owner, and then an agent, can work it out; what a game costs.
- **The settlement:** turns to reach a goal against a simple rule that takes
  the nearest gain; what looking ahead in code adds; requests a turn.

Each runs with nothing drawn where it can, as the orders test did, and each
report ends with what it means for a world, an item, the kit or the
protocol.
