## What it is

Five to twenty agents in one world, each its own, sharing one queue for
thinking so the machine isn't swamped. They idle, wander, follow and patrol by
simple rules, with captions, and act only through a broker that checks each
action. Nothing waits on a model to draw a frame.

## Done looks like

Five agents appear at once, with no room joined, nothing paid and no model
needed for them to move; it still works with no graphics card for models.
